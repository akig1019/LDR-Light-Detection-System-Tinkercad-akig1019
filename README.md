# LDR-Light-Detection-System-Tinkercad-akig1019
A responsive light-sensing circuit designed and simulated in Tinkercad. This project utilizes an Arduino Uno and a Photoresistor (LDR) to monitor ambient light levels and trigger a visual output (LED) based on a defined threshold. Ideal for learning basic ADC (Analog-to-Digital Conversion) and sensor integration.
